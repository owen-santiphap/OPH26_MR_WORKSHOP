## 💡 แนวคิด: "เป้าหมาย" ต่างจาก "AI Agent" อย่างไร?

ตลอด 3 ขั้นที่ผ่านมา เป้าหมาย (`BP_Target`) เป็นแค่ **วัตถุ** — มันลอยนิ่งอยู่เฉยๆ
รอให้คุณยิง มันไม่รู้ว่าคุณอยู่ตรงไหน และไม่เคยตัดสินใจอะไรเลย

**AI Agent ต่างออกไป** มันทำงานเป็นวงจร 3 จังหวะ:

```text
   [ 1. SENSE ]          [ 2. DECIDE ]              [ 3. ACT ]
     รับรู้        ➔        ตัดสินใจ          ➔        ลงมือทำ
  "ฉันเห็นผู้เล่น"      "เขาอยู่ไกลเกิน 150 ซม.       "บินเข้าหาเขา
                          ฉันควรเข้าไปหา"            แล้วหันหน้าไปทางเขา"
```

ในขั้นนี้ เราจะปลุก **นกฟีนิกซ์** ที่คาบเป้าหมายเอาไว้ ให้มัน**มองเห็นคุณ
หันมาหาคุณ แล้วบินไล่ล่าคุณในห้องเรียนจริง** — และคุณต้องยิงเป้าที่มันคาบอยู่ให้ได้

> **🧠 จุดสำคัญ:** เราจะไม่ยิงตัวนก — เราจะยิง**เป้าหมายที่นกคาบอยู่**
> ตัวนกจะถูกตั้งค่าให้กระสุน**ทะลุผ่านไปได้**

---

## ⚠️ ความปลอดภัย — อ่านก่อนเริ่ม

ขั้นนี้มีวัตถุบินเข้าหาคนที่สวมแว่นอยู่ ดังนั้น:

- ⚠️ ตั้งค่า **Max Speed = 200** เสมอ (ค่าเริ่มต้นคือ 1200 ซึ่ง**เร็วเกินไปมาก**)
- ⚠️ ต้องมีระยะหยุด **150 ซม.** เพื่อไม่ให้นกทะลุเข้ามาในกล้อง (ทำให้เวียนหัว)
- ⚠️ **ต้องมีเพื่อนคอยดูแล** คนที่สวมแว่นเสมอ — ผู้เล่นมักถอยหลังชนโต๊ะจริง

## 🧩 ของที่มีให้อยู่แล้ว (ไม่ต้องสร้างใหม่)

`BP_BirdTarget` ถูกเตรียมชิ้นส่วนไว้ให้แล้ว เหลือแค่ "ต่อสมอง" ให้มันเท่านั้น:

| มีให้แล้ว ✅ | หน้าที่ |
|---|---|
| `FloatingPawnMovement` | ทำให้บินได้ (ลอยได้ ไม่ตกพื้น) |
| `PawnSensing` | ดวงตา — ใช้มองหาผู้เล่น |
| `AIControllerClass` | ช่องเสียบ "สมอง" (`BP_BirdAIController`) |
| `BP_Target` | เป้าหมายที่แตกกระจาย + นับคะแนนได้อยู่แล้ว |

**สิ่งที่คุณจะทำ:** ใส่โมเดลนก + ใส่เป้าให้มันคาบ + ต่อ Blueprint ประมาณ 12 โหนด

## ขั้นตอนที่ 4.1: เปิด `BP_BirdTarget` และจัดชิ้นส่วน

1. ใน Content Drawer ไปที่: `Content/TargetGame/Blueprints/` ➔ ดับเบิลคลิก **`BP_BirdTarget`**

### 🗑️ ลบ `BirdMesh` ทิ้ง

2. ในพาเนล **Components** คลิกเลือก **`BirdMesh`** ➔ กด **Delete**

   *(มันเป็น Static Mesh ซึ่งใส่โมเดลนกที่มีอนิเมชันไม่ได้ และเดี๋ยวเราจะเอา
   `BP_Target` ตัวจริงมาแทนหน้าที่ของมัน)*

### 🐦 ลากนกฟีนิกซ์เข้ามา

3. ใน Content Drawer เปิด: `Content/phoenix/SkeletalMeshes/`
4. **ลาก `phoenix`** เข้าไปวางในพาเนล **Components** โดยหย่อนลงบน **`DefaultSceneRoot`**

   *(เป็นท่าเดียวกับตอนที่คุณลาก `SK_FPGun` ไปวางบน `MotionController_R` ในขั้นที่ 2!
   Unreal จะสร้าง Component และใส่โมเดลให้อัตโนมัติในขั้นตอนเดียว)*

5. คลิกเลือก Component **`phoenix`** ที่เพิ่งเกิดขึ้น แล้วตั้งค่าในพาเนล **Details**:

| หมวด | ค่าที่ต้องตั้ง |
|---|---|
| **Animation ➔ Animation Mode** | `Use Animation Asset` |
| **Animation ➔ Anim to Play** | `phoenix_Anim` |
| **Animation ➔ Looping** | ติ๊กถูก ✅ |
| **Collision ➔ Collision Presets** | **`NoCollision`** ⬅️ **สำคัญมาก!** |
| **Transform ➔ Rotation (Yaw)** | ปรับให้หัวนกหันไปทางแกน **+X** |
| **Transform ➔ Scale** | ย่อ/ขยายให้ปีกกางกว้างประมาณ 50–80 ซม. |

> **🎯 ทำไมต้อง `NoCollision`?**
> เพราะเราต้องการให้กระสุน **ทะลุผ่านตัวนก** ไปโดนเป้าหมายที่มันคาบอยู่
> ถ้าไม่ตั้งค่านี้ กระสุนจะไปหยุดที่ตัวนก แล้วจะยิงเป้าไม่โดนเลย

### 🎯 ใส่เป้าหมายให้นกคาบ

6. คลิก **`+ Add`** ➔ ค้นหา **Child Actor** ➔ เปลี่ยนชื่อเป็น **`CarriedTarget`**
7. ตั้งค่าในพาเนล **Details**:
   - **Child Actor Class**: เลือก **`BP_Target`**
   - **Transform ➔ Location**: `(X=0, Y=0, Z=-40)` *(ให้เป้าห้อยอยู่ใต้ตัวนก
     เหมือนนกกำลังคาบมันอยู่)*

**โครงสร้างที่ถูกต้อง:**

```text
BP_BirdTarget (Pawn)
└── DefaultSceneRoot
    ├── phoenix           Z =   0    ⬅️ ตัวนก (กระสุนทะลุผ่าน)
    ├── CarriedTarget     Z = -40    ⬅️ เป้าหมาย (ยิงตรงนี้!)
    ├── FloatingPawnMovement
    └── PawnSensing
```

## ขั้นตอนที่ 4.2: ตั้งค่าสมองและความเร็ว

   > **นี่คือช่วงเวลาที่เรา "ใส่สมอง" ให้มัน!** ค่านี้คือสิ่งที่อนุญาตให้
   > `BP_BirdAIController` เข้ามาควบคุมนกตัวนี้ ถ้าไม่ตั้งค่านี้ นกจะไม่ขยับเลย

### 🐌 ตั้งความเร็ว (เพื่อความปลอดภัย)

3. คลิกเลือก **`FloatingPawnMovement`** ➔ ตั้งค่า:
   - **Max Speed**: **`200`** ⬅️ **ห้ามลืม!** (ค่าเดิม 1200 เร็วจนอันตราย)
   - **Acceleration**: `600`

### 👁️ ปรับดวงตา

4. คลิกเลือก **`PawnSensing`** ➔ ตั้งค่า:
   - **Sight Radius**: `3000` *(ระยะมองเห็น ครอบคลุมทั้งห้องเรียน)*

   - **Peripheral Vision Angle**: `90` *(มุมมองด้านข้าง)*
   - **Only Sense Players**: ติ๊กถูก ✅ *(สนใจแค่ผู้เล่น ไม่สนนกตัวอื่น)*

## ขั้นตอนที่ 4.3: สร้างตัวแปรความจำ

AI ต้อง "จำ" ได้ว่ามันเจอคุณแล้วหรือยัง:

1. ในพาเนล **My Blueprint** ➔ หัวข้อ **Variables** ➔ คลิก **`+`**
2. ตั้งชื่อว่า **`IsHunting`**
3. เปลี่ยน **Variable Type** เป็น **Boolean**
4. กด **Compile** หนึ่งครั้ง แล้วปล่อยค่าเริ่มต้นไว้เป็น **ไม่ติ๊ก** (false)

---

## ขั้นตอนที่ 4.4: ต่อ Blueprint — วงจร 3 จังหวะของ AI

> **หมายเหตุ:** ถ้าเจอโหนด `BeginPlay` / `Tick` เดิมที่เป็น**สีเทาจางๆ**
> แปลว่ามันถูกปิดอยู่ ให้คลิกขวา ➔ **Node ➔ Enable (Always)** หรือลบทิ้งแล้ววางใหม่

### 🔍 จังหวะที่ 1 — SENSE (รับรู้)

1. คลิกเลือก **`PawnSensing`** ในพาเนล Components
2. ในพาเนล **Details** เลื่อนลงไปหาหัวข้อ **Events** ➔ คลิกปุ่ม **`+`** ที่ **On See Pawn**
3. ต่อสายตามนี้:

```text
[ On See Pawn (PawnSensing) ]
            │
            ▼
    [ Set IsHunting ]  ☑ ติ๊กถูก
```

> **เกิดอะไรขึ้น:** ทันทีที่นก "มองเห็น" คุณ มันจะจำไว้ว่า "เจอเป้าหมายแล้ว!"

### 🤔 จังหวะที่ 2 + 3 — DECIDE & ACT (ตัดสินใจ และ ลงมือทำ)

4. ต่อสายบน **Event Tick** (ทำงานทุกเฟรม) ตามผังนี้:

```text
[ Event Tick ]
      │
      ▼
[ Branch ] ◄──────────── [ Get IsHunting ]          ⬅️ "ฉันเจอเขาแล้วหรือยัง?"
      │ True
      ▼
[ Branch ] ◄──────────── [ Get Distance To ] ◄── [ Get Player Pawn ]
      │ True                   (ผลลัพธ์ > 150.0)     ⬅️ "เขายังไกลเกิน 150 ซม. ไหม?"
      ▼
[ Add Movement Input ]                               ⬅️ "บินเข้าหาเขา!"
   ├─ World Direction ◄── [ Get Unit Direction (Vector) ]
   │                          From ◄── [ Get Actor Location (self) ]
   │                          To   ◄── [ Get Actor Location ] ◄── [ Get Player Pawn ]
   └─ Scale Value = 1.0
      │
      ▼
[ Set Actor Rotation ] ◄── [ Find Look at Rotation ]  ⬅️ "หันหน้าไปทางเขา"
                              Start  ◄── [ Get Actor Location (self) ]
                              Target ◄── [ Get Actor Location ] ◄── [ Get Player Pawn ]
```

**เคล็ดลับการต่อสาย:**
- วางโหนด **`Get Player Pawn`** แค่**ตัวเดียว** แล้วลากสายจากมันไปใช้ทั้ง 3 จุด
- ลากสายออกจาก `Get Distance To` ➔ ค้นหาโหนด **`>`** (greater) ➔ พิมพ์ `150.0` ในช่องล่าง
- โหนด `Set Actor Rotation` ทำให้นกบิน**เอาหัวนำ** ถ้าไม่ใส่ นกจะบินแบบไถลข้างๆ
  แล้วอนิเมชันกระพือปีกจะดูผิดธรรมชาติมาก

### 🏆 จังหวะที่ 3 — SCORE (นับคะแนน)

**ไม่ต้องต่ออะไรเพิ่มเลย!** เพราะ `CarriedTarget` คือ `BP_Target` ตัวจริง
มันจึงมีระบบแตกกระจาย + เสียง + นับคะแนน ติดตัวมาให้เรียบร้อยแล้ว

5. กด **Compile** ✅ และ **Save**

## ขั้นตอนที่ 4.5: ทดสอบบนจอคอมพิวเตอร์ก่อน (ยังไม่ต้องใส่แว่น)

> **💡 ทำไมต้องทดสอบบน PC ก่อน?**
> เพราะสมองของ AI **ไม่เกี่ยวกับว่าเราจะแสดงผลบนจอหรือบนแว่น**
> ทดสอบบนจอง่ายกว่า เร็วกว่า และทุกคนทำพร้อมกันได้โดยไม่ต้องรอคิวแว่น!

1. เปิดด่าน `Content/FirstPerson/Maps/FirstPersonMap`
2. ตรวจสอบใน **World Settings** ว่า **Default Pawn Class** เป็น **`BP_FirstPersonCharacter`**
3. **ลาก `BP_BirdTarget`** เข้าไปวางในด่าน ให้ห่างจากจุดเริ่มประมาณ **400 ซม.** และสูง **Z ≈ 150**
4. กด **Play** แล้วตรวจสอบทีละข้อ:

- [ ] นกลอยอยู่ **กระพือปีก** ไม่ใช่ยืนแข็งกางแขน (T-pose)
- [ ] นกหัน**หัวไปข้างหน้า** ไม่ใช่บินไถลข้างๆ
- [ ] เมื่อคุณเดินเข้าไปในระยะมอง นก**หันมาหาคุณแล้วบินเข้าหา**
- [ ] นก**หยุดห่างประมาณ 150 ซม.** ไม่พุ่งเข้ามาชนหน้าคุณ
- [ ] ยิงเป้าที่ห้อยอยู่ใต้นก ➔ **แตกกระจาย + มีเสียง + คะแนนเพิ่ม**

## ขั้นตอนที่ 4.6: ปล่อยนกเข้าสู่ห้องเรียนจริง (Mixed Reality)

1. เปิดด่าน `Content/TargetGame/VR_MR/Levels/LVL_TargetGame_MR`
2. **ลาก `BP_BirdTarget` เข้าไป 2 ตัว** โดยวางให้:
   - สูงประมาณ **Z ≈ 150 ซม.**
   - ห่างจาก `PlayerStart` ประมาณ **3–4 เมตร**
   - อยู่เหนือ**พื้นที่โล่ง** ไม่ติดโต๊ะหรือเก้าอี้จริง
3. กด **Save** (`Ctrl + S`)
4. คลิก **`...`** ข้างปุ่ม Play ➔ เลือก **VR Preview** ➔ สวมแว่น

## 🏆 ไคลแมกซ์: เมื่อ AI ออกล่าในห้องเรียนจริง

- คุณมองเห็นห้องเรียนจริง โต๊ะจริง และเพื่อนๆ ผ่านกล้อง Passthrough
- **นกฟีนิกซ์ 2 ตัวกำลังกระพือปีกลอยอยู่กลางห้องเรียนจริง** พร้อมคาบเป้าหมายไว้
- ทันทีที่มัน**มองเห็นคุณ** — มันหันหัวมาทางคุณ แล้ว**เริ่มบินไล่ล่า**
- คุณต้องหมุนตัว เล็ง แล้วยิงเป้าที่มันคาบให้แตกก่อนที่มันจะเข้ามาใกล้!
- **เพล้ง!** เป้าแตกกระจาย คะแนนขึ้น — นกบินจากไปมือเปล่า

> **🧠 สิ่งที่คุณเพิ่งสร้าง:**
> ไม่ใช่แค่วัตถุที่ขยับได้ตามสคริปต์ที่เขียนไว้ล่วงหน้า
> แต่เป็น **Agent ที่รับรู้สภาพแวดล้อม ตัดสินใจเอง แล้วลงมือทำ**
> — และมันตัดสินใจว่า **"เป้าหมายของฉันคือคุณ"**
